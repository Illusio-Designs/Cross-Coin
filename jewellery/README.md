# Luxury Jewellery Store - Premium Ecommerce

A sophisticated, high-end jewelry ecommerce storefront built with Next.js 14, React, and Tailwind CSS.

## Features

- 🎨 Luxurious Gold & Black Design
- 💎 Premium Jewelry Collections
- 🚀 Next.js 14 App Router
- 📱 Mobile-First Responsive
- 🛒 Advanced Cart System
- 🔍 Live Search
- 💳 Checkout Flow
- 👤 Customer Account
- ⚡ Optimized Performance
- 🎭 Elegant Animations

## Getting Started

```bash
# Install dependencies
npm install

# Run development server (port 3001)
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3001](http://localhost:3001) to view the store.

## Color Scheme

- **Primary Black**: #000000 - Elegance and sophistication
- **Gold**: #D4AF37 - Luxury and premium quality
- **Accent Gold**: #C9A961 - Subtle highlights
- **Light Gold**: #F4E4C1 - Backgrounds and accents

## Tech Stack

- **Framework:** Next.js 14 (App Router)
- **UI Library:** React 18
- **Styling:** Tailwind CSS
- **State Management:** Zustand
- **Animations:** Framer Motion
- **Icons:** Lucide React
