# KNITWINK - Luxury Socks E-commerce

A modern, responsive e-commerce website for KNITWINK premium socks brand.

## Features

- 🎨 Modern, minimalist design inspired by luxury fashion brands
- 📱 Fully responsive (mobile, tablet, desktop)
- ⚡ Built with Next.js 14 for optimal performance
- 🎭 Tailwind CSS for styling
- 🚀 Fast page loads and smooth animations

## Getting Started

### Installation

```bash
cd Frontend-1
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
npm start
```

## Design Philosophy

The design follows a minimalist, luxury aesthetic with:
- Clean typography (Inter + Montserrat)
- Generous white space
- Bold, impactful hero sections
- Smooth transitions and hover effects
- Mobile-first responsive design
